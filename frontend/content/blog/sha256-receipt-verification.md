# How SHA256 Protects Your Receipt Integrity

Every receipt generated by receiptmaster includes a SHA256 hash — a cryptographic fingerprint that proves the document hasn't been modified since creation.

## What Is SHA256?

SHA256 (Secure Hash Algorithm 256-bit) is a one-way function that takes any input and produces a fixed-length 64-character hex string:

```
SHA256: a3f8e2d1c9b74e62f05a8d3c1b7e4f2a9d6c8b0e...
```

Two key properties: **deterministic** (same input = same hash) and **collision-resistant** (practically impossible for different inputs to match).

## How receiptmaster Uses It

1. Receipt data is rendered into an HTML template
2. HTML is converted to PDF via Playwright
3. The HTML snapshot is hashed using SHA256
4. The hash is stored in the database and printed on the receipt

## Why This Matters

**Tax Audits** — Authorities need proof that digital invoices haven't been altered. SHA256 provides exactly that.

**Dispute Resolution** — Verify the original receipt matches the stored hash to prove authenticity.

**EU Compliance** — The EN 16931 standard recommends integrity verification for electronic invoices. SHA256 is an accepted method.

## Verification Flow

```
Original HTML → SHA256 → Stored Hash
                            ↓
Retrieved HTML → SHA256 → Compare
                            ↓
                  Match? ✓ Authentic
                  Differ? ✗ Tampered
```

The HTML snapshot is stored separately from the PDF, ensuring you always have raw data to re-verify.

## Key Takeaway

SHA256 hashing provides mathematical proof that a document is unchanged. It doesn't encrypt your data — the receipt is still readable — but it proves authenticity. Every receiptmaster plan includes this at no extra cost.
