# Як SHA256 захищає цілісність ваших чеків

Кожен чек, згенерований receiptmaster, містить SHA256 хеш — криптографічний відбиток, що доводить незмінність документа з моменту створення.

## Що таке SHA256?

SHA256 (Secure Hash Algorithm 256-bit) — одностороння функція, що перетворює будь-який вхід у фіксований 64-символьний рядок:

```
SHA256: a3f8e2d1c9b74e62f05a8d3c1b7e4f2a9d6c8b0e...
```

Дві ключові властивості: **детермінованість** (однаковий вхід = однаковий хеш) та **стійкість до колізій** (практично неможливо знайти два різних входи з однаковим хешем).

## Як це працює в receiptmaster

1. Дані чеку рендеряться в HTML-шаблон
2. HTML конвертується в PDF через Playwright
3. HTML-знімок хешується через SHA256
4. Хеш зберігається в базі даних та друкується на чеку

## Чому це важливо

**Податкові перевірки** — Органи потребують доказів, що цифрові рахунки не були змінені.

**Вирішення спорів** — Перевірте оригінальний чек на відповідність збереженому хешу.

**Відповідність EU** — Стандарт EN 16931 рекомендує верифікацію цілісності. SHA256 — прийнятний метод.

## Потік верифікації

```
Оригінальний HTML → SHA256 → Збережений хеш
                                ↓
Отриманий HTML → SHA256 → Порівняння
                                ↓
                    Збіг? ✓ Автентичний
                    Різниця? ✗ Підроблений
```

## Ключовий висновок

SHA256 хешування надає математичний доказ незмінності документа. Воно не шифрує дані — чек залишається читабельним — але доводить автентичність. Кожен план receiptmaster включає це безкоштовно.
