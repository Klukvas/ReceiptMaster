# Як SHA256 захищає цілісність ваших чеків

Коли receiptmaster створює документ, він фіксує саме той вміст, з якого зроблено PDF, і записує його SHA256-хеш. Так система помітить, якщо збережений вміст колись зміниться.

## Що таке SHA256?

SHA256 (Secure Hash Algorithm 256-bit) — одностороння функція, що перетворює будь-який вхід у фіксований 64-символьний рядок:

```
SHA256: a3f8e2d1c9b74e62f05a8d3c1b7e4f2a9d6c8b0e...
```

Дві ключові властивості: **детермінованість** (однаковий вхід = однаковий хеш) та **стійкість до колізій** (практично неможливо знайти два різних входи з однаковим хешем).

## Як це працює в receiptmaster

1. Дані документа рендеряться в HTML-шаблон
2. HTML конвертується в PDF через Playwright
3. HTML-знімок хешується через SHA256
4. Знімок і його хеш зберігаються разом із документом

Хеш зберігається на нашому боці. Він не друкується на документі й не показується в застосунку.

## Чому це важливо

**PDF відповідає тому, що було створено** — Коли документ потрібно сформувати знову зі збереженого знімка, receiptmaster спершу заново обчислює хеш і порівнює його зі збереженим. Якщо вони різняться, документ не збирається зі зміненого вмісту.

**Історія не переписується** — Якщо згодом змінити реквізити компанії, шаблони чи ціни, уже створені документи не зміняться: вони зберігають зафіксований вміст.

**Чим це не є** — Хеш не є електронним підписом. Сам по собі він не робить документ відповідним податковим вимогам чи правилам ЄС щодо електронних рахунків; перевірте, що вимагає законодавство вашої країни.

## Потік перевірки

```
Оригінальний HTML → SHA256 → Збережений хеш
                                ↓
Збережений HTML  → SHA256 → Порівняння перед формуванням
                                ↓
                    Збіг? ✓ Формуємо
                    Різниця? ✗ Відмовляємо
```

HTML-знімок зберігається окремо від PDF, тож документ можна сформувати знову саме з того вмісту, який було видано.

## Ключовий висновок

SHA256-хешування допомагає receiptmaster зберігати створені документи такими, якими ви їх видали. Воно не шифрує дані й не є підписом. Кожен план receiptmaster включає це безкоштовно.
