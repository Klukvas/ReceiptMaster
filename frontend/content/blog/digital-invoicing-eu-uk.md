# Цифрове виставлення рахунків в ЄС

Європейський Союз послідовно рухається до обов'язкового електронного виставлення рахунків.

## Стандарт EN 16931

Основний стандарт ЄС для електронних рахунків визначає модель даних, формат та методи верифікації цілісності. Хоча зараз він застосовується переважно для B2G, мандати B2B розширюються.

## Верифікація цілісності

Стандарт рекомендує включати верифікацію цілісності. Прийнятні методи:

- **Цифрові підписи** (кваліфіковані електронні підписи)
- **EDI з узгодженими процедурами**
- **Криптографічне хешування** (наприклад, SHA256)

receiptmaster використовує SHA256 на кожному чеку.

## Вимоги зберігання

Регуляції вимагають зберігати рахунки мінімум 5–10 років. Цифрові рахунки повинні забезпечувати:

- **Читабельність** — перегляд в будь-який момент
- **Цілісність** — відповідність оригіналу
- **Автентичність** — підтвердження походження

receiptmaster зберігає PDF та HTML-знімок з SHA256 хешем.

## GDPR

Рахунки містять персональні дані. За GDPR потрібно обробляти їх законно, зберігати безпечно та надавати доступ на запит. receiptmaster використовує PostgreSQL Row-Level Security для ізоляції даних.

## Практичні кроки

1. Використовуйте систему з верифікацією цілісності
2. Зберігайте рахунки цифрово протягом необхідного періоду
3. Підтримуйте мови ваших клієнтів
4. Регулярно експортуйте та архівуйте дані
